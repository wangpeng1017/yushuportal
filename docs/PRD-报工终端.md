## 产品定位

**生产现场数字化工作站**：为车间一线操作工提供沉浸式、单屏专注的生产任务执行界面，模拟iPad终端操作体验。

### 核心用户
- 车间一线操作工
- CNC机床操作员
- 生产班组长

### 核心场景
- 开工报工
- 查看作业指导书和工程图纸
- 录入检验数据
- 设备状态监控
- 异常呼叫（Andon）

## 功能详细设计

### F001: Pad模拟器UI外壳
**状态**: 🟢 已完成 | **完成日期**: 2026-06-25

#### 需求描述
将原有全屏Web界面改造为iPad Pro样式的平板模拟器，提供沉浸式终端体验。

#### 设计规格
- **外壳尺寸**: 1194px × 746px
- **屏幕圆角**: 16px
- **外壳圆角**: 24px
- **外壳边框**: 12px padding
- **摄像头**: 顶部居中，8px圆形装饰
- **背景**: 渐变紫色（#667eea → #764ba2）
- **材质**: 黑色外壳，带高光和阴影效果

#### 技术实现
```css
.pad-wrapper {
  width: 1194px;
  height: 746px;
  background: #000;
  border-radius: 24px;
  padding: 12px;
  box-shadow: 0 20px 60px rgba(0,0,0,0.5);
  position: relative;
}

.pad-screen {
  width: 100%;
  height: 100%;
  border-radius: 16px;
  overflow: auto;
}
```

### F002: 底部Dock操作按钮
**状态**: 🟢 已完成 | **完成日期**: 2026-06-25

#### 需求描述
在Pad底部固定悬浮5个操作按钮，类似macOS的Dock效果，始终可见可点击。

#### 按钮列表
1. **▶ 开工** - 扫码/点击开始计时
2. **报工** - 填写完成数量
3. **暂停** - 选择停机代码
4. **检验** - 录入控制计划
5. **返修** - 发起返工申请

#### 设计规格
- **位置**: Pad底部上方16px，水平居中
- **按钮尺寸**: 128px × 56px
- **间距**: 8px gap
- **背景**: 毛玻璃效果（rgba(255,255,255,0.85) + backdrop-filter: blur(20px)）
- **圆角**: 12px
- **阴影**: 0 8px 32px rgba(0,0,0,0.12)
- **z-index**: 100
- **定位**: position: absolute（相对于pad-wrapper）

#### 技术实现
```css
.action-bar {
  position: absolute;
  bottom: 16px;
  left: 50%;
  transform: translateX(-50%);
  background: rgba(255, 255, 255, 0.85);
  backdrop-filter: blur(20px);
  z-index: 100;
}
```

#### 交互逻辑
- 点击"开工"按钮 → 触发开工流程（扫码/弹窗确认）
- 点击"报工"按钮 → 打开报工表单弹窗
- 点击"暂停"按钮 → 展开停机代码选择面板
- 点击"检验"按钮 → 打开检验控制计划抽屉
- 点击"返修"按钮 → 打开返工申请表单

### F003: 工程图纸内嵌显示
**状态**: 🟢 已完成 | **完成日期**: 2026-06-25

#### 需求描述
将工程图纸直接显示在作业指导书卡片中，不需要点击弹出，提升查看效率。

#### 设计规格
- **位置**: 作业指导书卡片内，操作步骤下方
- **图纸格式**: SVG矢量图
- **内容**: 主视图、侧视图、尺寸标注、标题栏、技术要求
- **尺寸**: 自适应卡片宽度，max-width: 100%
- **边框**: 1px solid #CBD5E1
- **圆角**: 6px

#### SVG内容
- 主视图（圆柱体轮廓）
- 侧视图（矩形剖面）
- 尺寸标注（φ120、120mm高度）
- 粗糙度符号（Ra1.6）
- 标题栏（图号、材料、比例）
- 技术要求（2条）

## 技术实现要点

### 1. 布局架构
```
HTML/Body (渐变紫色背景，居中布局)
└── .pad-wrapper (iPad外壳)
    ├── .pad-camera (顶部摄像头装饰)
    ├── .pad-screen (屏幕区域，可滚动)
    │   ├── .crumb (面包屑)
    │   ├── .cols (主内容区)
    │   │   ├── .col-left (左侧工单信息)
    │   │   └── .main (中间作业指导书)
    │   └── (内容区域)
    └── .action-bar (底部Dock按钮，悬浮固定)
```

### 2. z-index层级管理
| 元素 | z-index | 说明 |
|---|---|---|
| .pad-camera | 100 | 摄像头装饰 |
| .action-bar | 100 | 底部Dock按钮 |
| .bottom-drawer | 1000 | 检验控制计划抽屉（默认隐藏） |

### 3. 关键CSS修复
- **bottom-drawer默认隐藏**: `display: none` → 只有`.show`时才`display: flex`
- **action-bar定位**: 从pad-screen内移到pad-wrapper内，避免随内容滚动
- **导航栏/右侧栏隐藏**: `display: none !important`
